# Expo_App_Dev
Personal App Development with Expo

I really love the idea of the BRICK (https://getbrick.app/products/brick), basically a NFC device that links to an app and prevents you from using pre-selected apps until you "unlock" your phone by tapping the brick again. I think its a great idea, and I want to create an application that allows me to do the same. I want to create the application to place on my phone, and easiest method for app development is through Expo Go.

This repository will be me figuring out how to recreate this app as a personal project.
